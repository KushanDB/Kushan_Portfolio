# Kushan's Portfolio

A modern, responsive portfolio website built with React.

## Features

- Hero section with typewriter effect
- About section with personal information
- Skills showcase
- Projects gallery
- Education timeline
- Contact form
- Responsive design

## Getting Started

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm start
```

The app will open at [http://localhost:3000](http://localhost:3000)

### Build for Production

```bash
npm build
```

## Technologies Used

- React
- React Router
- CSS3
- JavaScript (ES6+)

## Assets

Place your images in the `public/assets` folder:
- `portrait.jpg` - Your main portrait
- `portrait-2.jpg` - Alternative portrait
- `project1.jpg`, `project2.jpg`, `project3.jpg` - Project screenshots
- `contact-illustration.jpg` - Contact section image
- `resume.pdf` - Your resume file
