## 🔄 Easy Theme Switching

Want to switch back or try different colors? 

### Quick Switch Guide:

**Option 1: Keep both themes**
1. Save current `index.css` as `emerald-theme.css`
2. Create `crimson-theme.css` with old colors
3. Swap import in `index.js`

**Option 2: Just change variables**
All colors are in `:root` CSS variables. Change just the top section!

**Option 3: Mix & match**
Keep emerald base, use crimson accents:
```css
--accent: #7b001c;           /* Crimson back */
--gold: #C9A86A;             /* Keep brass gold */
--bg-main: #0F2027;          /* Keep emerald */
```
