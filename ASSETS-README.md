# Assets Setup Instructions

## Required Assets

Please add the following files to make your portfolio complete:

### 📁 Fonts (`src/assets/fonts/`)
- **Qasira.ttf** - The Qasira font file for the logo
  - Download the Qasira font and place it here
  - The font is already configured in `src/index.css`

### 📁 Images (`src/assets/images/`)

1. **hero-profile.png** - Your profile photo
   - Recommended: Cut-out image with transparent background
   - Size: Square (e.g., 800x800px)
   - Used in the Hero section

2. **contact-illustration.png** - Contact section illustration
   - Any clean illustration related to communication/contact
   - Recommended size: 400-600px width
   - Used in the Contact section

3. **project-1.png** - Project thumbnail (optional)
   - Screenshot or mockup of your projects
   - Recommended size: 600x400px (landscape)
   - You can add more project images (project-2.png, project-3.png, etc.)

### 📄 Additional Files (Optional)

- **public/Kushan-Jayathunga-CV.pdf** - Your CV/Resume for download
  - Place in the `public` folder
  - Used by the "Download CV" button

## How to Add Files

1. Download/prepare your images
2. Place them in the respective folders:
   - Fonts → `src/assets/fonts/`
   - Images → `src/assets/images/`
   - CV → `public/`

## Customization Notes

### Update Social Media Links (Hero.jsx)
Replace the placeholder links with your actual profiles:
- GitHub: `https://github.com/your-username`
- LinkedIn: `https://www.linkedin.com/in/your-linkedin`
- Facebook: `https://facebook.com/your-profile`
- WhatsApp: `https://wa.me/94700000000`

### Update Email (Footer.jsx)
Replace `youremail@example.com` with your actual email address.

### Update School Names (Education.jsx)
Replace "Your School Name" with your actual school names in the Education section.

Once you've added these files, your portfolio will be complete! 🎉
