## 🆘 Getting Help

**Port already in use?**
- Edit `.env` and change PORT to 3000 or 8000

**Missing module errors?**
- Run `npm install` again

**Image import errors?**
- Make sure all images are added to `src/assets/images/`
- File names must match exactly (case-sensitive)

**Styling looks different?**
- Clear browser cache
- Check if `index.css` loaded correctly
